## 2. Hướng dẫn các bước mở chi tiết

1. Mở trình duyệt web (Google Chrome, Microsoft Edge hoặc Firefox).
2. Dán liên kết trang web vào thanh địa chỉ: `https://discorsmemaybeo-maker.github.io/K20_Fortfolio_CNTT20-02/` và nhấn **Enter**.
3. Bấm vào menu **Giới thiệu** để xem thông tin tổng quan và định hướng cá nhân.
4. Bấm vào menu **Dự án** hoặc nút **Xem dự án** ở phần đầu trang để chuyển đến danh sách bài tập thực hành.
5. Cuộn xuống phần **Liên hệ**, điền đầy đủ *Họ tên*, *Email*, *Lời nhắn* vào ô nhập liệu rồi bấm nút **Gửi lời nhắn** để xem dữ liệu truyền qua trang `ket-qua.html`.
